# 🎭 Тени прошлого (Shadows of the Past)

2D top-down психологический хоррор на **C++17 + raylib**.
Вдохновлён **Darkwood**: тьма, ограниченный обзор, безумие как главная угроза.

## 📖 О проекте

Слава возвращается в деревню детства через 10 лет после исчезновения сестры Анны.
Мир игры — его собственный бред, вызванный чувством вины. Четыре концовки.

Полный сюжет и дизайн — в [docs/PROJECT.md](docs/PROJECT.md).

## 🚀 Быстрый старт

### Требования
- C++17-совместимый компилятор (GCC 9+, Clang 10+, MSVC 2019+)
- CMake 3.15+
- raylib 4.5+

### Сборка
```bash
git clone https://gitlab.com/<твой_юзер>/shadows-of-the-past.git
cd shadows-of-the-past
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/ShadowsOfThePast
```

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| W A S D | Ходьба |
| Shift | Бег (тратит стамину) |
| E | Взаимодействие / закрыть диалог |

| Esc | Выход (автосейв) |
