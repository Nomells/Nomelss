# 🎭 Тени прошлого — Shadows of the Past

> [!abstract] О проекте
> 2D top-down психологический хоррор на **C++17 + raylib**.
> Вдохновлён **Darkwood**: ограниченный обзор, тьма, стамина,
> безумие как основная угроза, инвентарь с паузой.
> Сюжет — путь человека через вину к принятию правды.

## 1. Обзор проекта (GDD)

### 1.1. Основные данные

| Параметр | Значение |
|----------|----------|
| Название | Тени прошлого (Shadows of the Past) |
| Жанр | 2D top-down психологический хоррор |
| Перспектива | Вид сверху, ограниченный обзор (конус взгляда) |
| Стек | C++17, raylib 5.x |
| Сборка | CMake 3.15+ |
| Платформы | Windows, Linux, macOS |
| Целевая длительность | 3–5 часов |
| Целевая аудитория | 18+, любители атмосферных хорроров, Darkwood, Silent Hill, Lone Survivor |
| Модель распространения | TBD (itch.io / Steam) |

### 1.2. Ключевые фишки

- **Тьма и конус обзора** — видно только то, что перед тобой. Вне света — неизвестность.
- **Безумие как главная угроза** — враги не убивают, они сводят с ума.
- **Четыре концовки**, зависящие от действий, а не от выбора в финальном меню.
- **Секретный финал «Правда»** — доступен только тем, кто прошёл без агрессии и собрал все записки.
- **Мир как метафора** — каждая локация = стадия осознания вины.

### 1.3. Core loop

```
Исследовать локацию → Найти записку/предмет → Прочитать/подобрать
       ↓
   Растёт безумие от тьмы и врагов → Искать свет/безопасность
       ↓
   Получить ключ → Открыть новую локацию → Узнать часть правды
       ↓
   (повтор до финала)
```

### 1.4. Эстетика

- **Палитра:** почти монохром. Чёрный, тёмно-серый, ржаво-коричневый, багровый акцент.
- **Свет:** только от конуса взгляда + слабый круг вокруг тела. Источники света редки и ценны.
- **Звук:** тишина + редкие шёпоты, скрип, дыхание. Резкие звуки = скримеры.
- **UI:** минималистичен, живёт по краям экрана, никогда не перекрывает центр.

### 1.5. Управление

| Клавиша | Действие |
|---------|----------|
| W A S D | Ходьба |
| Shift | Бег (тратит стамину) |
| E | Взаимодействие / закрыть диалог |
| I | Инвентарь (пауза мира) |
| Esc | Выход (автосейв) |

## 2. Сюжет

### 2.1. Пролог — Письмо из прошлого

**Слава**, 27 лет. 10 лет живёт в городе, пытаясь забыть детство. Каждую ночь снится одно и то же: деревня, лес, сестра **Анна**, уходящая в туман.

Однажды получает письмо без обратного адреса. Внутри — записка детским почерком:

> *«Я всё ещё здесь. Я жду тебя в том месте, где мы были счастливы. Приезжай, пока не стало слишком поздно. Но помни: не всё, что ты увидишь, — правда.»*

В конверте — старый ключ и фотография: он и Анна на крыльце бабушкиного дома. Дата на обороте — **17 августа 2003 года**. День, когда Анна исчезла.

### 2.2. Часть 1 — Дом бабушки

Деревня **пуста**. Туман, заколоченные окна, тишина. В доме всё как 10 лет назад: чайник, фотографии, икона. На столе — **дневник бабушки**:

> *«Она приходит во сне. Она зовёт. Я больше не могу сопротивляться.»*
> *«Мы не должны были трогать тот камень.»*
> *«Если ты читаешь это, Слава, — беги. Но если останешься — найди три ключа. И не верь ангелам.»*

Находим: **фотографию** (у дедушки нет лица), **дневник**, **ржавый ключ** (первый из трёх). При взятии фото — свет гаснет, в зеркале Анна: *«Ты не должен был возвращаться»*.

### 2.3. Часть 2 — Пустая деревня

Дома стоят **неправильно**, как в кошмаре. Встречаем **Странника** в плаще:

> *«Три ключа откроют тебе врата: один — в прошлое, второй — в страх, третий — в правду. Но будь осторожен: у каждого ключа есть цена.»*

Появляются **тени** — существа без лиц. Они наблюдают, шепчут имя. Рассудок постепенно падает.

### 2.4. Часть 3 — Школа

Головоломка: найти парту Анны по подсказкам (тетрадь, рисунок, дневник). Награда — **ключ от больницы** (второй ключ).

**Призраки учеников** ведут по коридорам. Рыжий мальчик шепчет:

> *«Мы все исчезли в тот день. Мы играли в лесу. Мы нашли что-то… старое. Она первая прикоснулась к нему. И оно проснулось.»*

Правда: дети нашли **древний камень**, Анна коснулась первой.

### 2.5. Часть 4 — Больница

Заброшенное здание. **Ключ от церкви** (третий ключ) + медкарта Анны:

> *«Пациент: Анна Соколова, 9 лет. Диагноз: диссоциативное расстройство, галлюцинации, ночные кошмары. Утверждает, что «видит людей без лиц» и «тень, которая следует за ней».»*

**Доктор** (призрак) пытается убедить Славу, что Анна — плод его фантазии:

> *«Ты создал её. Ты создал этот мир. Ты создал нас. Всё это — тюрьма, которую ты построил, чтобы не смотреть правде в глаза.»*

Записи: Анна **выжила**, но говорила чужим голосом и предсказывала смерти. Через месяц пропала окончательно.

### 2.6. Часть 5 — Церковь

Старая книга: легенда о **Тени** — духе, что питается страхом. Был запечатан в камне; если потревожить — заберёт **первую жертву** как «проводника».

**Священник**:
> *«Анна не пропала. Она стала проводником тени. Она всё ещё здесь — в лесу. Но чтобы её спасти, ты должен отдать что-то взамен.»*

**Ключевой вопрос:** спасти Анну, пожертвовав собой, или оставить её, чтобы закрыть проклятие навсегда.

### 2.7. Часть 6 — Тёмный лес

С тремя ключами и **амулетом** (найден на поляне) входим в глубину леса. Лес **1000×1000** — деревья, волки, тени. Время идёт иначе. Слышим голос Анны: то зовёт, то проклинает. Видим своё прошлое — моменты, когда мог помочь, но не помог.

В центре — **древний камень**. Перед Славой — финальный выбор.

## 4. Концовки

### 4.1. 🟢 Хороший финал — «Искупление»

**Условия:** есть амулет, рассудок > 20, все три ключа.

Слава использует амулет — Тень возвращается в камень, но забирает **память о сестре**. Он выходит из леса, не помня, кого искал. Анна жива и здорова, но не помнит его. Деревня оживает.

> *«Иногда, чтобы спасти кого-то, нужно отпустить прошлое.»*

### 4.2. 🟡 Нейтральный финал — «Жертва»

**Условия:** нет амулета, но есть все ключи, рассудок > 0.

Слава занимает место Анны — становится новым **проводником тени**. Анна выходит из леса одна.

> *«Он заплатил цену, которую не должен был платить никто.»*

### 4.3. 🔴 Плохой финал — «Безумие»

**Условия:** рассудок = 0, либо смерть от волков.

Слава теряет связь с реальностью, остаётся в лесу. Становится **новым монстром** — существом без лица.

> *«Он искал правду. И правда поглотила его.»*

### 4.4. ⚫ Секретный финал — «Правда»

**Условия:** собраны **все** записки, **ни один** враг не убит, найден вход в скрытую комнату под церковью.

Хроники: **Анна умерла в 2003**. Всё, что видел Слава — **его собственный бред**, вызванный чувством вины. Белая палата, окно с решёткой, врач: *«Слава, вы снова видели её?»*

> *«Некоторые тени живут только в наших головах. Но от этого они не менее реальны.»*

## 5. Механики

### 5.1. Здоровье (HP)

| Параметр | Значение |
|----------|----------|
| Максимум | 100 |
| Урон от волков | 15–25 за удар |
| Регенерация | Нет |
| Аптечки | Есть, редки |
| Смерть при | HP ≤ 0 |

### 5.2. Стамина

| Параметр | Значение |
|----------|----------|
| Максимум | 100 |
| Расход при беге | 30/сек |
| Восстановление | 18/сек |
| Задержка восстановления | 0.8 сек |
| Бег невозможен при | стамина < 5 |

### 5.3. Безумие (Sanity) — ключевая механика

| Параметр | Значение |
|----------|----------|
| Максимум | 100 |
| Убыль в темноте | 1.5/сек |
| Убыль рядом с тенью | 8/сек |
| Восстановление в свету | 2/сек |
| Эффекты при < 40 | Дрожание экрана, шёпоты, галлюцинации |
| Эффекты при < 20 | Сильное искажение, ложные тени |
| Game Over при | 0 |

> [!warning] Безумие не лечится «аптечкой»
> Восстановить рассудок можно только в безопасных зонах (костёр, освещённая комната) или предметами-талисманами.

### 5.4. Свет

- **Круг вокруг игрока** — радиус 150 px (боковое зрение).
- **Конус взгляда** — длина 450 px, угол 70°.
- **Ядро конуса** — 55% длины, ярче (255 вместо 200).
- **Дрожание** при sanity < 40 — смещение ±(40−sanity)·0.3 px.

### 5.5. Взаимодействие

- Радиус взаимодействия: **70 px**.
- Подсказка `[E] ...` появляется над ближайшим объектом.
- Объекты: **Note, Item, Key, Photo, Door**.

### 5.6. Инвентарь

- Сетка **6×4** = 24 слота.
- Открытие клавишей **I** → мир на паузе.
- API: `addItem`, `hasItem`, `removeItem`.
- Пустой слот = пустая строка.

## 6. Враги

### 6.1. Тени

| Параметр | Значение |
|----------|----------|
| HP | 60 (не убиваются в привычном смысле) |
| Радиус | 18 px |
| Обзор (игрок стоит) | 180 px |
| Обзор (игрок бежит) | 350–400 px |
| Скорость патруля | 60 px/сек |
| Скорость погони | 110 px/сек |
| Урон | Не HP, а **безумию** (8/сек вблизи) |

**FSM:** `Patrol → Investigate → Chase`

- **Patrol** — бродит вокруг точки спавна (радиус 80–180 px), меняет цель каждые 2–5 сек.
- **Investigate** — идёт к последней замеченной точке игрока.
- **Chase** — преследует, пока видит.

### 6.2. Волки *(планируются)*

- Агрессивны, атакуют при виде.
- Урон 15–25 HP за удар.
- Скорость 130 px/сек.
- В секретном финале их нельзя убивать.

### 6.3. Призраки *(планируются)*

- Не атакуют.
- Ведут по коридорам к цели.
- Дают подсказки.

## 7. Локации

### 7.1. Дом бабушки (House)

**Назначение:** обучение, атмосфера, первый ключ.

**Карта (14×11):**
```text
##############
#............#
#............#
#...D........#
#............#
#............#
#....#.......#
#....#.......#
#............#
#............D
##############
```

**Интерактивные объекты:**

| Объект | Тип | Что даёт |
|--------|-----|----------|
| Дневник бабушки | Note | «Найди три ключа. Не верь ангелам» |
| Фотография | Photo | Скример, первая галлюцинация |
| Ржавый ключ | Key | Открывает подвал (ключ №1) |
| Дверь на улицу | Door | → Village |

### 7.2. Пустая деревня (Village)

**Назначение:** знакомство со Странником, первые тени.

**Карта (28×16):** большая открытая область, дома по периметру.

**Интерактив:**
- Возврат в дом (Door).
- Записка Странника на стене (Note).
- **2 тени** (враги).

### 7.3. Школа (School) *(планируется)*

**Назначение:** головоломка «найди парту Анны», ключ №2.

**Интерактив:**
- Тетрадь, рисунок, детский дневник — подсказки.
- Парта Анны (головоломка) → **ключ от больницы**.
- Призраки учеников (NPC-указатели).

### 7.4. Больница (Hospital) *(планируется)*

**Назначение:** ключ №3, встреча с Доктором, правда о выживании Анны.

**Интерактив:**
- Медицинская карта Анны (Note).
- Записи врача (Note).
- Диалог с Доктором.
- **Ключ от церкви**.

### 7.5. Церковь (Church) *(планируется)*

**Назначение:** легенда о Тени, финальный выбор.

**Интерактив:**
- Старая книга (Note).
- Диалог со Священником.
- **Скрытая комната** (для секретного финала).

### 7.6. Тёмный лес (Forest) *(планируется)*

**Назначение:** финальная локация.

**Параметры:**
- Размер **1000×1000 тайлов** (64 000 × 64 000 px — не влезет в память как тайл-карта).
- **Процедурная генерация** деревьев.
- Волки, тени.
- В центре — **древний камень**.

```
    ├───────────────────────────┤
    │  Systems: LightSystem,    │
    │  SaveSystem               │
    └───────────────────────────┘
```

**Правила:**
- `entities` знают о `world`, но не наоборот.
- `ui` знает о `entities` (для отрисовки статов), не знает о `world`.
- `systems` независимы: используют только `core/Config` и raylib.
- `Game` — единственное место, где всё встречается.

### 9.3. Ключевые принципы

1. **RAII** — объекты на стеке (`Player player;`, `Inventory inv;`), умные указатели только там, где нужно динамическое владение (`std::unique_ptr<Location>`).
2. **Разделение update/draw** — никогда не рисуем из логики и не логичим из рисования.
3. **`deltaTime` везде** — любое движение, таймер, анимация умножаются на `dt`.
4. **Константы в `Config.h`** — ни одного магического числа в коде логики.
5. **Виртуальные деструкторы** у базовых классов с наследованием.

## 10. Игровые системы

### 10.1. LightSystem

**Назначение:** тьма в стиле Darkwood.

**Принцип:**
1. `LoadRenderTexture` создаёт холст размером окна.
2. `BeginTextureMode(target)` → рисуем чёрным фоном, затем добавляем белые пятна там, где «видно».
3. `BLEND_ADDITIVE` — источники света складываются.
4. `EndTextureMode()`.
5. `BLEND_MULTIPLIED` — накладываем маску на сцену: где белое — видно, где чёрное — нет.

**Ключевой код:**
```cpp
BeginTextureMode(target);
    ClearBackground(BLACK);
    BeginBlendMode(BLEND_ADDITIVE);
        DrawCircleV(playerPos, LIGHT_RADIUS, {90,90,90,255});
        DrawCircleSector(playerPos, CONE_LENGTH,
                         angle - halfAngle, angle + halfAngle, 48,
                         {200,200,200,255});
    EndBlendMode();
EndTextureMode();
```

**Ограничения:**
- Не работает на Web без поддержки RenderTexture (raylib Web — да, но с ограничениями).
- Пока нет теней от стен (планируется raycast).

**Идеи на будущее:**
- Мерцание от свечей.
- Свет, вырывающийся из окон.
- Реакция врагов на свет (боятся/идут).

### 10.2. Inventory

**API:**
```cpp
bool addItem(const std::string& id);
bool hasItem(const std::string& id) const;
void removeItem(const std::string& id);
```

**UI:** сетка 6×4, slotSize = 64 px, pad = 6 px. Рисуется поверх всего, мир на паузе.

### 10.3. Dialogue

**Печатная машинка:** 45 символов в секунду. `skip()` мгновенно показывает весь текст. Закрытие — E / Space / Enter.

**UI:** блок внизу экрана, высота 200 px, margin 40 px. Заголовок + текст.

### 10.4. SaveSystem

**Формат `save.txt`:**
```
location house
position 352.0 512.0
hp 100
sanity 87.5
stamina 62.0
inventory _ _ key_rusty diary_grandma _ _
```

**Что сохраняется:** локация, позиция, HP, стамина, безумие, содержимое инвентаря.

**Когда:** при выходе (`~Game`). Автозагрузка при старте — если файл существует.

### 10.5. EnemyAI

**FSM:**
```
Patrol ──[игрок замечен]──→ Chase
   ↑                            │
   │                            │
   └──[потерян]── Investigate ←─┘
                     │
                     └──[дошёл]──→ Patrol
```

**Восприятие:**
- Игрок **стоит** → видит на 180 px.
- Игрок **идёт** → видит на 350 px.
- Игрок **бежит** → видит на 400 px (шум).

**Движение:** по осям отдельно (X потом Y) — не застревает в углах.

### 10.6. HUD

- **HP** — красная полоса, x=20, y=30.
- **Стамина** — жёлтая полоса, y=70.
- **Рассудок** — синяя полоса, y=110. Краснеет при < 40, становится багровой при < 20.

## 11. Сборка и запуск

### 11.1. Требования

- **Компилятор:** GCC 9+, Clang 10+, MSVC 2019+.
- **CMake:** 3.15+.
- **raylib:** 4.5+ (установить глобально или подтянуть через `FetchContent`).
- **OS:** Windows 10+, Linux (Ubuntu 20.04+), macOS 11+.

### 11.2. Установка raylib

**Linux (Ubuntu/Debian):**
```bash
sudo apt install libraylib-dev
```

**macOS (Homebrew):**
```bash
brew install raylib
```

**Windows:** скачать с [github.com/raysan5/raylib/releases](https://github.com/raysan5/raylib/releases), распаковать в `C:/raylib`, добавить `C:/raylib/include` в include path и `C:/raylib/lib` в library path.

### 11.3. CMakeLists.txt

```cmake
cmake_minimum_required(VERSION 3.15)
project(ShadowsOfThePast CXX)

set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

find_package(raylib REQUIRED)

file(GLOB_RECURSE SOURCES src/*.cpp)

add_executable(ShadowsOfThePast ${SOURCES})
target_include_directories(ShadowsOfThePast PRIVATE src)
target_link_libraries(ShadowsOfThePast PRIVATE raylib)

add_custom_command(TARGET ShadowsOfThePast POST_BUILD
    COMMAND ${CMAKE_COMMAND} -E copy_directory
        ${CMAKE_SOURCE_DIR}/assets
        $<TARGET_FILE_DIR:ShadowsOfThePast>/assets
)
```

### 11.4. Сборка

```bash
cmake -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j
./build/ShadowsOfThePast
```

### 11.5. IDE

- **VS Code:** CMake Tools + C/C++.
- **CLion:** открыть как CMake-проект.
- **Visual Studio:** File → Open → CMake.
- **QtCreator:** File → Open File or Project → CMakeLists.txt.

## 12. Стиль кода

### 12.1. Именование

| Сущность | Стиль | Пример |
|----------|-------|--------|
| Класс | PascalCase | `Player`, `TileMap` |
| Метод | camelCase | `handleInput`, `tryMove` |
| Переменная | camelCase | `playerPos`, `currentLocation` |
| Константа | UPPER_SNAKE | `SCREEN_WIDTH`, `TILE_SIZE` |
| Enum value | PascalCase | `TileType::Wall` |
| Файл класса | PascalCase | `Player.cpp`, `LightSystem.h` |

### 12.2. Правила

- `#pragma once` в каждом заголовке.
- Все заголовки включаются первыми, потом стандартная библиотека.
- Комментарии — на русском, объясняют **почему**, а не **что**.
- Функции **< 20 строк** — если больше, разбить.
- `const` везде, где можно: `void draw() const`.
- `override` для всех переопределений.
- Никаких `new`/`delete` вручную — `std::unique_ptr`, объекты на стеке.
- Никаких `using namespace std;`.
- RAII: ресурс живёт ровно столько, сколько объект.

### 12.3. Коммиты

**Формат:** `<тип>: <короткое описание>`

| Тип | Когда |
|-----|-------|
| `feat:` | Новая фича |
| `fix:` | Исправление бага |
| `docs:` | Документация |
| `refactor:` | Рефакторинг без изменения поведения |
| `chore:` | Рутина (обновление зависимостей) |
| `assets:` | Добавлены спрайты/звуки |

**Пример:** `feat: добавил FSM для тени (Patrol → Chase)`
